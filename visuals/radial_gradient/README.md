# Radial Gradient

## Concepts

- normalized coordinates
- aspect-ratio correction
- distance fields
- length()
- interpolation
- mix()

## Parameters

### Transform

u_offset

Moves the gradient center.

### Gradient

u_radius

Controls the distance over which the gradient fades.

### Appearance

u_color_center

Color at the center.

u_color_edge

Color at the edge.

u_intensity

Brightness multiplier.
