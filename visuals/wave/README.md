# Wave

## Concepts

- normalized coordinates
- aspect-ratio correction
- coordinate transforms
- sine functions
- periodic patterns
- animation with time
- interpolation

## Parameters

### Transform

u_offset

Moves the wave.

u_rotation

Rotates the wave direction.

u_scale

Scales the coordinate space.

### Wave

u_frequency

Controls the number of wave cycles.

u_amplitude

Controls the wave strength.

u_speed

Controls animation speed.

### Appearance

u_color_1

First wave color.

u_color_2

Second wave color.

u_intensity

Brightness multiplier.
