# Checkerboard

## Concepts

- normalized coordinates
- aspect-ratio correction
- coordinate transforms
- floor()
- mod()
- repetition
- grid patterns
- mix()

## Parameters

### Transform

u_offset

Moves the checkerboard.

u_rotation

Rotates the checkerboard.

u_scale

Scales the checkerboard.

### Checkerboard

u_cells

Number of checkerboard cells across the coordinate space.

### Appearance

u_color_1

First checker color.

u_color_2

Second checker color.

u_intensity

Brightness multiplier.
