# Noise

## Concepts

- normalized coordinates
- aspect-ratio correction
- coordinate transforms
- pseudo-random functions
- hash functions
- fract()
- dot products
- interpolation

## Parameters

### Transform

u_offset

Moves the noise field.

u_scale

Scales the coordinate space.

### Noise

u_noise_scale

Controls the size of noise features.

Higher values create smaller details.

u_speed

Animates the noise coordinates.

### Appearance

u_color_1

First noise color.

u_color_2

Second noise color.

u_intensity

Brightness multiplier.
